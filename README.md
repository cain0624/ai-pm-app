# AI 产品经理 · 学习与面试教练

把知识卡、刷题、错题反馈和模拟面试连接成个人练习闭环。

**作品形态：可运行学习工具 / 教练依赖模型服务**

[在线体验](https://cain0624.github.io/ai-pm-app/) · [个人作品集](https://kunyu-builds.s291623933.chatgpt.site/projects/ai-pm-app.html)

> 项目案例依据当前公开代码、页面、README 与提交记录整理。已实现、历史验证记录和下一步计划分别标明；模拟数据不作为真实业务结果。

## 背景

准备 AI 产品面试需要理解知识、练习表达并定位薄弱项。仅阅读题库不能证明会应用，也不能形成针对性的复习。

作品把移动端知识卡、选择题、播客拆解与面试教练连接到同一应用，让练习状态参与下一轮教学。



## 问题



- 刷过题不等于掌握；错题和收藏若不被后续练习使用，学习反馈会断开。
- 通用聊天教练看不到用户进度，难以针对薄弱点出题并解释。
- 真实模型接入需要工具调用支持、可用的浏览器跨域服务以及明确的未配置状态。

## 思考



- 把知识消费、知识检验与表达练习分开，再通过进度、收藏和错题状态连接起来。
- 给教练提供读取状态、取知识卡、发测验和记录结果的工具，让讲解依据来自本轮反馈。
- 基础题库和随机抽查可独立运行，模型教练是可选增强能力，降低初次使用门槛。

## 动作



- 提供五十张面试知识卡、五十道选择题、五期播客拆解，以及朗读、收藏、错题筛选。
- 实现教练工具调用循环和十题随机抽查，支持读进度、读取错题并呈现交互测验。
- 加入项目阐述、五分钟倒计时、十轮模拟面试与评分卡收藏。

## 优化



- 提交记录显示：针对未配置 Key 增加明确提示与设置入口，调整默认服务以解决跨域访问问题。
- 迭代选中状态、页面间距，并将模拟面试结果接回可收藏的评分卡。
- 下一步：把公开客户端中的默认凭据改为受控代理或用户配置，验证额度、失败恢复与评分一致性。

## 结果

已形成读卡 → 刷题 → 错题反馈 → 教练练习 → 模拟面试的可运行学习路径。题目数量来自已有内容，不代表题库覆盖率或学习效果。

教练表现依赖模型、function calling、服务可用性与额度；尚无真实面试通过率或长期学习收益数据。

- 建议衡量：错题复测正确率、工具调用成功率、练习完成率、评分一致性、模型失败恢复率和复习留存。
- 验收路径：做题并留下错题 → 打开教练 → 让教练读取进度 → 完成测验或模拟面试 → 查看反馈。

# AI 产品经理刷题 · AI 面试教练

一个单文件移动端风格的 AI 产品经理学习应用。

## 功能
- **首页**：50 道 AI PM 面试题（TikTok 式上下滑 + 语音朗读），收藏 / 标记 / 过滤
- **播客**：5 期 AI 播客图文拆解（含源音频播放）
- **刷题**：50 道选择题，错题本 + 只刷错题，可收藏
- **教练**：带工具调用循环的 AI 面试教练（真正的 agent）——读你的错题本/收藏、出交互式测验、看结果再讲解；还有「随机抽查」10 题闭环

## 使用
- 直接打开 `index.html`，或访问 GitHub Pages 部署地址
- 教练 Tab 需在「设置」填一个 OpenAI 兼容 API（OpenAI / 智谱 GLM / DeepSeek / OpenRouter / 本地 Ollama）
- 随机抽查与首页语音不需要 key

## 离线演示教练对话
```bash
python3 mock-llm.py   # 监听 127.0.0.1:8124
```
教练设置里填 `http://localhost:8124/v1`，模型名/key 随意。
